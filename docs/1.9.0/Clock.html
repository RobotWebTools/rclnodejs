function

(async) sleepFor(duration, contextopt) → {Promise.<boolean>}

Sleep for a specified duration. Equivalent to: clock.sleepUntil(clock.now() + duration, context) When using a ROSClock, this may sleep forever if the TimeSource is misconfigured and the context is never shut down. ROS time being activated or deactivated causes this function to cease sleeping and return false.
Parameters:
Name Type Attributes Default Description
duration Duration Duration of time to sleep for.
context Context <optional>
 null Context which when shut down will cause this sleep to wake early. If context is null, then the default context is used.

function

(async) sleepUntil(until, contextopt) → {Promise.<boolean>}

Sleep until a specific time is reached on this Clock. When using a ROSClock, this may sleep forever if the TimeSource is misconfigured and the context is never shut down. ROS time being activated or deactivated causes this function to cease sleeping and return false.
Parameters:
Name Type Attributes Default Description
until Time Time at which this function should stop sleeping.
context Context <optional>
 null Context whose validity will be checked while sleeping. If context is null, then the default context is used. If the context is found to be shut down before or by the time the wait completes, the returned promise resolves to false.
