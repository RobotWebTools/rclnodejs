# rclnodejs Web Demos

Browser demos built with `rclnodejs/web`. Select a demo for setup and usage instructions.

- [API Playground - Vanilla](./api-playground/vanilla/README.md): Explore ROS 2 topics, services, and actions in a plain HTML/JavaScript page, with no frontend build.
- [API Playground - Vite + TypeScript](./api-playground/vite-typescript/README.md): Explore the same ROS 2 APIs in a typed browser app built with Vite.
- [Manipulator Studio](./manipulator/README.md): Control a simulated two-joint arm from your terminal and visualize its motion in a read-only Three.js browser viewer.
